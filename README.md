# DELYVO — Delivery & Logistics

DELYVO is a modular delivery and logistics platform for Algeria.

## Services
- Dental Delivery
- General / Express Delivery
- E-commerce Delivery
- Restaurant Delivery
- Personal Delivery

## Architecture direction
Fleetbase is the initial open-source logistics foundation. DELYVO provides the product layer: brand, customer experience, service-specific workflows, dashboards and business logic.

## Development principle
The GitHub repository is the permanent source of truth, not any AI conversation.

Never commit secrets, API keys, passwords or real customer/patient data.

See `docs/PROJECT_CONTEXT.md` for the current project state.
