# DELYVO Delivery Workflow

## Standard
Created -> Accepted -> To Collect -> Collected -> In Transit -> Arrived -> Delivered

## Exceptions
- Cancelled
- Returned
- Problem / Exception

Every delivery receives a unique tracking ID such as DLV-2026-00482.

Dental deliveries can include case reference, material/work type, urgency, special handling, clinic and laboratory.

Do not invent medical/dental handling rules. Validate specialized requirements before automating them.

Potential proof of delivery: confirmation, signature, photo or OTP.

Potential notification events: created, accepted, pickup approaching, collected, in transit, delivered, exception.
