# DELYVO User Roles

- SUPER ADMIN: complete platform control.
- ADMIN: configurable operational management.
- DISPATCHER: deliveries, assignment and active operations.
- DRIVER: assigned deliveries, status, navigation and proof of delivery.
- DENTAL CUSTOMER: dentist, clinic or dental laboratory.
- BUSINESS CUSTOMER: e-commerce seller, restaurant or other business.
- PERSONAL CUSTOMER: individual customer.

Authorization must be enforced server-side, not only through hidden UI controls.
